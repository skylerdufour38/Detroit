## GitHub Pages

This project is designed to run as a static GitHub Pages website.

Example:

```text
https://USERNAME.github.io/REPOSITORY/
```

## GitHub Codespaces

The repository can be opened in GitHub Codespaces for development and testing.

```text
Code → Codespaces → Create codespace on main
```

## Archive Format

Each archived application is represented using an IPA-style package structure:

```text
Application.ipa
└── Payload/
    └── Application.app/
        ├── Info.plist
        ├── Application
        ├── Icon.png
        └── Resources/
```

> **Archive note:** The information above describes the archived package metadata supplied for this project. Availability, installation compatibility, signing, and authorization for installing historical iOS applications can vary by device and iOS version.
